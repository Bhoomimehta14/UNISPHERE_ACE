# 🎓 UNISPHERE - Campus Management System

A comprehensive campus management platform built with Next.js, designed to connect students, faculty, and administrators worldwide.

## 🌟 Features

### Student Portal
- Dashboard with academic overview
- Course management and grades tracking
- Interactive campus navigation with floor maps
- Event discovery and registration
- Resource booking system
- Canteen menu and ordering
- Personal timetable management

### Faculty Portal
- Assignment management
- Batch and student tracking
- Schedule management
- Resource allocation
- Canteen services

### Admin Portal
- User management system
- Timetable administration
- Request and approval workflows
- Resource management

## 🚀 Tech Stack

- **Framework:** Next.js 14.2.5
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Design:** Glassmorphism with custom animations
- **Architecture:** Role-based portal system

## 📦 Installation

```bash
# Clone the repository
git clone [your-repo-url]

# Install dependencies
npm install

# Run development server
npm run dev
```

## 🛠️ Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run start    # Start production server
npm run lint     # Run ESLint
```

## 🌐 Deployment
